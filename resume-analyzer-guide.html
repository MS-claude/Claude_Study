1. 서비스 개요

Resume Analyzer는 채용 담당자가 채용 사이트에서 이력서를 볼 때 실시간으로 AI가 분석해주는 크롬 확장프로그램입니다. 분석 결과는 Google Sheets에 자동으로 저장되며, 합/불합격 피드백이 쌓일수록 AI의 예측 정확도가 향상됩니다.

🤖
AI 분석
Google Gemini API가 포지션 JD와 이력서를 비교해 적합도를 0~100%로 산출
📊
Sheets 자동 저장
분석 결과·강약점·검토 의견이 Google Sheets에 자동 기록
🧠
학습 개선
합/불합격 피드백이 쌓이면 유사 포지션 예측 정확도가 높아짐
🖥️
사이드 패널 UI
브라우저 오른쪽에 400px 패널이 열려 페이지를 이동하지 않고 분석 가능

기술 스택

Chrome Extension MV3 JavaScript (ES2020+) Google Gemini 2.5 Flash/Pro Google Sheets API v4 Google OAuth2 HTML5 / CSS3
✅
별도 서버 불필요 모든 데이터는 사용자의 Google Sheets에 저장됩니다. 외부 백엔드 서버가 없으므로 유지비용이 없습니다.
📁

사용자 워크플로우 (단계별)

확장프로그램 아이콘 클릭 크롬 우측에 400px 사이드 패널이 열림. Service Worker가 openPanelOnActionClick 이벤트로 패널을 활성화.
포지션 선택 Sheets "소싱포지션" 탭에서 포지션 목록을 불러옴. 드롭다운에서 선택하면 JD 미리보기가 표시됨. "진행 중" 필터 토글 가능.
후보자 선택 또는 신규 입력 동일 포지션의 기존 후보자 목록이 표시됨. 신규 후보자면 이름을 입력하고 이력서 입력 단계로 진행.
이력서 입력 (3가지 방법 중 선택) ① 화면 캡처 · ② 텍스트 드래그 선택 · ③ 직접 붙여넣기. 스크롤 전체 캡처로 여러 페이지 한 번에 처리 가능.
AI 분석 실행 Gemini API에 JD + 이력서 + 과거 합/불합격 사례(few-shot)를 전송. JSON 형식으로 결과 수신 후 Sheets에 자동 저장.
결과 확인 적합도 게이지(0~100%), 지원 권고/보류/비권고 배지, 주요경력, 강점·약점 리스트, JD 항목별 충족 여부 표시.
피드백 입력 (합격/불합격) 검토 사유를 입력하고 합격 또는 불합격 버튼 클릭. Sheets "분석현황" 탭의 "검토결과" 열(H열)이 업데이트됨.

4. 이력서 입력 방법

이력서 내용을 AI에게 전달하는 방법은 3가지가 있으며, 상황에 맞게 선택합니다.

방법 1 — 화면 캡처 (스크린샷)

📷
채용 사이트에서 이력서 페이지를 열어 놓은 상태에서 사용. 이미지를 Gemini가 직접 읽어 텍스트를 추출합니다.
종류동작적합한 경우
단일 캡처 chrome.tabs.captureVisibleTab()으로 현재 화면 1장 촬영 이력서가 한 화면에 다 보일 때
스크롤 전체 캡처 85% 뷰포트 단위로 스크롤하며 여러 장 촬영 후 배열로 전송 이력서가 길어 여러 화면에 걸쳐 있을 때

방법 2 — 텍스트 선택 모드

  1. 사이드패널에서 "🖱️ 선택 모드 시작" 버튼 클릭
  2. Content Script가 웹페이지 상단에 파란색 툴바를 주입
    // 툴바 UI (웹페이지 최상단에 표시)
    [ 📋 분석할 이력서 텍스트를 드래그하여 선택하세요 ] [ 선택 완료 ] [ 취소 ]
  3. 이력서 텍스트를 마우스로 드래그하여 선택
  4. "선택 완료" 클릭 → chrome.runtime.sendMessage(TEXT_SELECTED)로 사이드패널에 전달
  5. 사이드패널에 선택된 텍스트 미리보기 표시

방법 3 — 직접 붙여넣기

"직접 입력" 탭에서 이력서 전문을 복사-붙여넣기합니다. 글자 수가 실시간으로 표시됩니다. PDF나 Word 파일의 내용을 텍스트로 복사할 때 유용합니다.

5. AI 분석 엔진 (Gemini API)

사용 모델

모델특징권장 사용
gemini-2.5-flash 빠른 응답, 낮은 비용 기본값 일반적인 이력서 분석
gemini-2.5-pro 더 높은 정확도, 복잡한 JD 처리 상세한 분석이 필요할 때

API 요청 구조

JavaScript // API 엔드포인트
POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={apiKey}

// 파라미터
temperature: 0.2 ← 낮은 값 = 일관된 결과 (창의성 최소화)
maxOutputTokens: 65536 ← 긴 이력서도 처리 가능한 최대값

AI 응답 형식 (JSON)

Gemini는 항상 아래 JSON 형식으로만 응답하도록 프롬프트에 강제되어 있습니다.

JSON 출력 예시 {
  "careerSummary": "A사 5년/백엔드, B사 3년/풀스택",
  "probability": 78, ← 포지션 적합도 (0~100)
  "summary": "경력이 풍부하고 기술 스택이 매칭됩니다.",
  "strengths": ["경력 풍부", "기술 스택 매칭"],
  "weaknesses": ["프로젝트 리딩 경험 부족"],
  "keyMatches": [
    { "requirement": "3년 이상 경력", "matched": true, "detail": "5년 경험" }
  ],
  "recommendation": "지원 권고" ← 지원 권고 | 지원 보류 | 지원 비권고
}

응답 파싱 (3단계 폴백)

모델이 JSON 형식을 벗어난 응답을 줄 경우를 대비해 3단계로 파싱을 시도합니다.

단계방법처리 대상
1단계직접 JSON.parse()완벽한 JSON 응답
2단계마크다운 백틱(```json) 제거 후 파싱코드블록으로 감싼 경우
3단계정규식으로 {...} 추출 후 파싱앞뒤에 설명 텍스트가 붙은 경우

6. Google Sheets 데이터 구조

스프레드시트에는 두 개의 탭이 필요합니다. 정확한 이름과 구조를 지켜야 합니다.

탭 1 — "소싱포지션" (포지션 정보)

⚠️
헤더는 5행에 있어야 합니다. 1~4행은 타이틀·설명 등 자유롭게 사용 가능.
A열B열C열D열E열
서칭코드 포지션명 JD 선호 조건 진행여부
K001-BE-001 카카오 백엔드 3년 이상 경력, Java/Spring... AWS 경험자 우대 진행 중
N002-FE-003 네이버 프론트엔드 React 2년 이상... TypeScript 필수 마감

탭 2 — "분석현황" (후보자 분석 결과)

ℹ️
헤더는 1행에 있어야 합니다. 분석 결과는 아래로 계속 추가됩니다.
A열B열C열D열E열F열G열H열I열
서칭코드 이름 서칭일 주요경력 종합평가 강점 약점 검토결과 분석내용
K001-BE-001 홍길동 2025-05-27 A사 5년/백엔드 경력 풍부, 스택 매칭 경력 풍부 리딩 경험 부족 합격 - 사유: 경력 {JSON...}

H열(검토결과)은 피드백을 입력하면 자동 업데이트됩니다. I열(분석내용)에는 AI가 반환한 전체 JSON이 저장됩니다.

Sheets API 호출 방식

sheets.js // 포지션 목록 조회
GET /spreadsheets/{id}/values/소싱포지션!A5:E

// 후보자 기록 추가
POST /spreadsheets/{id}/values/분석현황!A:I:append

// 검토결과 업데이트
PUT /spreadsheets/{id}/values/분석현황!H{rowIndex}

7. Google 인증 구조

Sheets API에 접근하려면 Google 계정 인증이 필요합니다. 확장프로그램은 크롬 내장 OAuth2 메커니즘을 사용합니다.

인증 방식: chrome.identity.getAuthToken()

✅
장점 크롬이 토큰을 자동으로 캐시하고 갱신합니다. 별도 Client Secret이 불필요하며, 한 번 로그인하면 이후 자동으로 인증됩니다.

최초 연결 과정

  1. 사이드패널 설정 탭에서 "🔗 Google 계정 연결" 버튼 클릭
  2. 크롬이 Google OAuth 동의 화면 표시 (Sheets 읽기/쓰기 권한 요청)
  3. 사용자가 권한 승인 → 크롬 내부에 토큰 캐시
  4. UI에 "✅ Google 계정 연결됨" 표시
  5. 이후 Sheets API 호출 시 자동으로 Bearer 토큰 사용 (사용자 개입 없음)

Google Cloud 사전 설정 (이미 완료됨)

항목값

요청 권한(Scope) https://www.googleapis.com/auth/spreadsheets

8. 학습 피드백 루프 (Few-Shot Learning)

피드백이 쌓일수록 AI의 예측 정확도가 높아지는 학습 구조입니다. 별도 모델 훈련 없이 프롬프트에 과거 사례를 포함시키는 "In-Context Learning" 방식입니다.

① 분석 실행
JD + 이력서 → Gemini
→
② AI 결과 수신
probability, 강점, 약점
→
③ Sheets 저장
분석현황 탭에 행 추가
↓
⑥ 다음 분석 시 자동 포함
프롬프트에 3개 사례 삽입
←
⑤ Sheets H열 업데이트
"합격 - 사유: 경력 풍부"
←
④ 피드백 입력
합격/불합격 + 사유

프롬프트에 포함되는 학습 데이터

Prompt (buildFewShotExamples) ## 동일 포지션 과거 사례 (학습용)

[결과: 합격 / 예측: 78%]
주요경력: A사 5년/백엔드, B사 3년/풀스택
---
[결과: 불합격 / 예측: 35%]
주요경력: C사 1년/프론트엔드
---
💡
효과 "이 포지션에서 합격한 사람은 경력 5년 이상이었다"는 패턴을 Gemini가 학습하여, 이후 유사 이력서에 더 높은 점수를 부여합니다. 피드백을 꾸준히 입력할수록 예측 정확도가 향상됩니다.

학습에 사용되는 사례는 해당 포지션의 최근 3개로 제한됩니다 (프롬프트 길이 제어).

⚙️

9. 확장프로그램 설치 방법

⚠️
이 확장프로그램은 Chrome Web Store에 등록되지 않은 내부용 도구입니다. "개발자 모드"로 설치해야 합니다.

1단계 — 확장프로그램 파일 준비

저장소를 로컬에 받아(아래 10번 항목 참조) resume-analyzer-extension 폴더를 확인합니다.

2단계 — 크롬에 설치

  1. 크롬 브라우저에서 주소창에 chrome://extensions/ 입력 후 Enter
  2. 우측 상단 "개발자 모드" 토글을 ON으로 켬
  3. "압축 해제된 확장프로그램을 로드합니다." 버튼 클릭
  4. 로컬에 받은 resume-analyzer-extension 폴더를 선택
  5. 확장프로그램 목록에 "Resume Analyzer" 가 추가됨을 확인
  6. 크롬 툴바에 확장프로그램 아이콘 핀 고정 (퍼즐 조각 아이콘 → 핀 클릭)

3단계 — 초기 설정

  1. 확장프로그램 아이콘 클릭 → 사이드패널 열림
  2. 패널 우측 상단 "⚙️ 설정" 클릭
  3. Google AI API 키 입력 (발급: aistudio.google.com/app/apikey)
  4. Google 스프레드시트 ID 입력 (Sheets URL에서 /d/ 뒤 ~ /edit 앞 문자열)
  5. "🔗 Google 계정 연결" 클릭 → OAuth 동의 화면에서 권한 승인
  6. 설정 저장 후 포지션 목록이 로드되면 설치 완료

Google Sheets 사전 준비

  1. 새 Google Sheets 생성
  2. 첫 번째 탭 이름을 정확히 "소싱포지션" 으로 변경
  3. 두 번째 탭 이름을 정확히 "분석현황" 으로 변경
  4. "소싱포지션" 탭의 5행에 헤더 입력: 서칭코드 | 포지션명 | JD | 선호 조건 | 진행여부
  5. "분석현황" 탭의 1행에 헤더 입력: 서칭코드 | 이름 | 서칭일 | 주요경력 | 종합평가 | 강점 | 약점 | 검토결과 | 분석내용
  6. 포지션 데이터를 소싱포지션 탭에 입력 후 스프레드시트 ID를 설정에 등록

11. 코드 업데이트 방법

코드가 수정되어 저장소에 반영된 경우, 아래 절차로 로컬 파일을 최신 상태로 갱신하고 크롬 확장프로그램에도 적용합니다.

로컬 코드 업데이트 (저장소 최신본 받기)

Bash # 1. 프로젝트 폴더로 이동
$ cd Claude_Study

# 2. 원격 저장소 변경사항 확인
$ git fetch origin

# 3. 현재 브랜치에 최신 코드 병합
$ git pull origin main

# 개발 브랜치를 사용 중이라면
$ git pull origin claude/kind-gates-8OAQw

크롬 확장프로그램 갱신

코드가 업데이트된 후 크롬에서 아래 단계로 확장프로그램을 갱신합니다.

  1. 크롬 주소창에 chrome://extensions/ 입력
  2. Resume Analyzer 카드에서 "새로고침(↺)" 버튼 클릭
  3. 버전 번호가 변경되었는지 확인 (manifest.json의 "version" 값)
  4. 열려 있는 사이드패널이 있다면 닫았다가 다시 열기
✅
로컬 설정(API 키, Sheets ID)은 유지됩니다. 설정값은 chrome.storage.local에 저장되어 확장프로그램을 새로고침해도 초기화되지 않습니다.

코드 수정 후 저장소에 반영하기

직접 코드를 수정하고 저장소에 올려야 할 경우 아래 절차를 따릅니다.

Bash # 1. 변경 파일 확인
$ git status

# 2. 변경 내용 확인
$ git diff

# 3. 수정 파일 스테이징 (예: popup.js만 추가)
$ git add resume-analyzer-extension/popup/popup.js

# 4. 커밋 (변경 이유를 명확히 작성)
$ git commit -m "fix: 스크롤 캡처 시 좌표 계산 오류 수정"

# 5. 원격 저장소에 푸시
$ git push -u origin claude/kind-gates-8OAQw

자주 사용하는 Git 명령어 요약

명령어설명
git status 변경된 파일 목록 확인
git diff 변경 내용(코드 비교) 상세 확인
git log --oneline -10 최근 10개 커밋 히스토리 확인
git pull origin main 원격의 최신 코드를 로컬에 반영
git stash 작업 중인 변경사항을 임시 보관 (pull 전 충돌 방지)
git stash pop 임시 보관한 변경사항 다시 적용
git checkout -b feature/xxx 새 기능 브랜치 생성
🚨
주의: git reset --hard, git push --force 사용 자제 이 명령어들은 커밋 기록을 덮어쓰거나 삭제할 수 있습니다. 확실한 이유 없이는 사용하지 마세요.

업데이트 후 문제가 생겼을 때 (롤백)

Bash # 직전 커밋 상태로 되돌리기 (변경사항 유지)
$ git revert HEAD

# 특정 커밋으로 파일만 복원 (커밋 기록 유지)
$ git checkout abc1234 -- resume-analyzer-extension/popup/popup.js

# 커밋 해시 확인
$ git log --oneline
